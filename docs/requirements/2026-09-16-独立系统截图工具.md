# 需求：独立系统截图工具

日期：2026-09-16

## 一屏摘要

- 目标：独立、高颜值、开箱即用的系统截图工具 Cropmark；整款产品都是成品，不是能截就行（R1、R7）
- 使用者：在任意应用里截屏、标注、复制/保存或取字的桌面用户（R1）
- 范围：首期必须同时交付 macOS、Windows、Linux 同一核心环，缺一不算完成：热键截取区域/窗口/全屏，预览标注（箭头/框/马赛克/文字框），复制或保存，离线 OCR 并在图上点选/划选文字，以及可开关的开机启动（R2、R3、R4、R5、R8）
- 关键行为：截完打开预览且未标注图进剪贴板；不必先改设置就能完成第一次截图；任一平台失败可见；整款界面（遮罩、预览、托盘、设置、错误）同一套完成度（R2、R3、R5、R7）
- 成功标准：三平台用热键走完核心环，Windows/Linux 颜值与易用不得明显低于 macOS（R2、R3、R4、R5、R7）
- 不做事项：录屏、滚动长图、截图历史画廊、云分享/云 OCR、未完成态的默认窗口主界面（R6、R7）

## 完整需求

### R1 独立系统截图工具

行为：使用者得到独立桌面截图工具 Cropmark，可在任意前台应用上完成截取、标注、复制、保存和取字。界面、安装包与托盘只使用 Cropmark 这一名称与自有图标，不依附其它应用。

适用与失败边界：首期必须同时交付 macOS、Windows 与 Linux 桌面，缺任一平台不算本期完成。macOS 是体验标杆，不是唯一交付平台。工具未运行时全局热键不生效。界面、安装包、菜单和设置中不得出现其它产品的名称、图标或入口。

验收：

- 只要本工具在运行，就能完成截取到预览的核心环，无需先打开其它应用
- 发布或验收清单同时包含 macOS、Windows、Linux 可运行包或可验证构建，而不是只交 Mac
- 主界面、关于页与托盘菜单只呈现 Cropmark 名称与图标

### R2 区域、窗口与全屏截取

行为：工具以托盘或菜单栏形式常驻。使用者通过全局热键或托盘入口选择区域、窗口或全屏。区域模式用遮罩拖出矩形并显示尺寸；窗口模式截取使用者选中的可见窗口；全屏模式截取目标屏的全部可见内容。提供短暂延时，以便打开菜单或弹出层后再截。截取成功后打开预览，同时把未标注图像放入剪贴板。

适用与失败边界：热键仅在进程运行时有效，可在设置中修改；默认绑定不得在未询问时接管系统截图快捷键。开机启动见 R8。工具自身的遮罩、尺寸条、工具栏和托盘弹出不得进入画面。使用者取消截取时，不改写剪贴板、不写文件、不打开预览。延时期间使用者可操作其它应用，延时结束再截当时屏幕。图像像素尺寸必须匹配该屏缩放（含 Retina 与 Windows/Linux 高 DPI），不得以逻辑点尺寸冒充像素。多屏时，区域与全屏以指针所在屏为准；窗口截取以被选窗口所在屏的缩放为准。

验收：

- 用全局热键进入区域截取，拖出矩形后出现预览，其它应用中粘贴得到该 PNG
- 窗口截取结果为该窗口内容，且不含本工具 UI
- 在 2x 缩放屏上，全屏截图像素宽高约为该屏逻辑分辨率的 2 倍，画面不糊、不错位
- 取消或按 Esc 后，剪贴板与磁盘没有新截图，预览不出现
- 选择短暂延时后打开菜单，延时结束的截图包含该菜单

### R3 预览、标注、复制与保存

行为：预览中可使用箭头、矩形框、马赛克和文字输入框标注，可撤销。文字框点在图上放置，直接输入后成为画面上的文字，复制或保存的 PNG 含该文字。使用者可将当前预览复制到剪贴板，或保存为 PNG。允许不标注直接复制或保存。标注后再复制，剪贴板更新为带标注的图。

适用与失败边界：首期标注为箭头、矩形框、马赛克、文字框。文字框是使用者自己打的字，不是 R4 的识别取字。文字工具下点击是放置或编辑输入框，不是画矩形或选 OCR 文本；与取字、其它标注需能切换。空内容或取消编辑的文字框不进入复制/保存结果。中文等输入法候选窗可走系统原生。马赛克必须破坏原像素，不能只加半透明遮罩。保存使用系统文件对话框；使用者取消保存或写入失败时，预览中的图仍可继续标注、复制或再次保存。复制失败时预览保留，并给出可见错误。

验收：

- 添加箭头、框、马赛克和一行文字后复制，其它应用粘贴结果含这些标注且能读到所输入文字
- 在图上点出文字框，用中文输入法打字并确认后，预览里看见该文字；复制/保存的 PNG 同样含该文字
- 取消编辑或留空的文字框不出现在复制/保存结果中
- 保存得到可被系统图片查看器打开的 PNG 文件
- 取消保存对话框后仍可复制或继续标注
- 马赛克覆盖的文字在导出 PNG 中不可读

### R4 图上点选与划选文字

行为：预览中可离线识别当前图像上的文字。识别成功后，使用者能在图上点选词句或划选一段，把选中文本复制到剪贴板。同一识别结果也提供复制全部识别文本。识别在本机完成，不把图像或文本发送到网络。至少覆盖印刷体中文和英文。

适用与失败边界：取字是 OCR 的主路径，不是整图复制的替代说明。取字模式下，在文字上拖动是选文本，不是画矩形标注；标注与取字互不抢手势，需能切换。不保证手写、艺术字、过小字号或严重倾斜的准确率。识别失败、无文字或没有可选区域时，给出可见提示，截图仍可标注、复制图像或保存，且不得清掉剪贴板里已有的截图。复制选中文本后剪贴板为文本；使用者仍可在预览里再复制图像。

验收：

- 含清晰中英印刷体的截图，断网识别后，点选一个词或划选一行，其它应用粘贴得到对应片段而不是整图全部文字
- 同一预览中可以把全部识别文本一次复制出来
- 取字模式下拖过一行文字会高亮该段文本，不会画出标注框
- 无文字或识别失败时出现提示，此时若截取时已把图放入剪贴板，其它应用仍能粘贴该图
- 完成一次识别与取字的过程中，工具不因 OCR 而发起网络请求

### R5 三平台权限与可见失败

行为：macOS、Windows、Linux 在使用者已授予截屏权限的会话中，均能完成 R2–R4 的核心环。各平台按本系统的截屏权限模型请求授权；拒绝或尚未授权时说明原因，并给出打开系统设置或门户提示的可操作指引。Windows 与 Linux 不是后补平台。

适用与失败边界：未授权或系统未提供可用截屏接口时，不得把全黑图、空白图或超时空结果当作成功。Linux 不承诺每一个合成器与发行版；当桌面会话没有可用截屏接口（例如 Wayland 下门户不可用且无其它可用路径）时，失败原因可见，但这不取消 Linux 作为首期交付平台。Windows 必须按显示器 DPI 出图；截取失败时同样可见错误。首期不做移动端。macOS 关闭屏幕录制类权限后的失败体验是三平台的对照标杆。

验收：

- macOS、Windows、Linux 各自在已授权会话中，用热键完成区域截取、打开预览并复制
- macOS 关闭屏幕录制权限后发起截取，出现授权指引，不生成被当作成功的全黑图
- Windows 在截取失败时显示错误，不把空白图或黑图当作成功
- Linux 在无法截屏的会话中显示失败原因，而不是静默结束
- 混合 DPI 多屏环境下，在高 DPI 屏截取的图像清晰且与该屏缩放匹配

### R7 整款高颜值与简单易用

行为：整款工具按同一套成品界面交付，不只遮罩和预览：托盘/菜单栏、设置、权限与错误提示、延时、标注和取字都好看、好懂。区域截取为全屏遮罩，未选区域压暗，选区边界与像素尺寸清晰。预览为无浏览器外壳的紧凑浮动面板；图、少量标注工具、复制、保存、取字同屏可达，复制是最明显的下一步。图上点选/划选文字有可见高亮；文字框写在图上。界面跟随系统浅色/深色。默认热键即可完成第一次截图，不必先打开设置。托盘入口短：截取、设置、退出。

适用与失败边界：系统文件对话框、系统权限设置页和输入法候选窗可保持系统原生。主流程不得用带标题栏的普通应用窗、浏览器地址栏/标签或未样式化的默认控件顶替遮罩、预览或设置。不得要求先填一长串选项或走多步向导才能截图。Windows 与 Linux 允许原生控件差异，但不允许缺遮罩、用简陋对话框代替预览，或颜值/易用明显低于 macOS。不要求复杂动画；若有过渡，不得卡顿、残影或遮挡选区。设置只服务热键、开机启动等少数项，不能变成功能堆砌。

验收：

- 安装并授予截屏权限后，只按默认热键就能完成「区域截取 → 预览 → 粘贴」，中途不打开设置
- 区域截取时看不到普通窗口标题栏；未选区域明显压暗，选区有清晰边框和像素宽高
- 预览面板同时提供图像、箭头/框/马赛克/文字框、复制、保存和取字，复制动作一眼能找到，且没有地址栏或浏览器标签；标注文字写在图上，OCR 选中文字时图上出现高亮
- 托盘或菜单栏条目少而可读，能发起截取、打开设置和退出，没有长列表或隐藏入口才是主路径
- 同一套标注（含文字框）在 1x 与 2x 屏上边缘清晰，不发糊、不发虚
- Windows 与 Linux 的遮罩、预览、托盘和错误提示达到与 macOS 同等完成度，而不是仅弹出系统截图或空白窗
- 权限拒绝或复制/保存失败时看到产品内说明，而不是堆栈或空白失败

### R8 开机启动

行为：设置里提供开机启动开关。打开后，使用者登录桌面时本工具在托盘或菜单栏自行运行，无需再手动打开。关闭后，登录时不再自动运行。默认关闭。

适用与失败边界：三平台都要提供该开关。默认不强开，第一次截图不必先打开它。开启成功后登录不弹出主窗口，只常驻托盘/菜单栏。系统拒绝登录项（需额外批准或桌面不支持）时，开关回到实际未开启状态，并给出可见说明，不得显示已开启却登入后没有进程。卸载或关闭开关后，登录项被移除。

验收：

- 新安装后设置中开机启动为关；登录后工具不会自己出现
- 打开开关并完成系统允许后，下一次登录能在托盘或菜单栏看到本工具，无需再点安装包
- 再关掉开关后，再一次登录时工具不会自动运行
- 系统不允许登录项时，开关不是「开着但其实没启动」，并出现产品内说明

## 不做事项

### R6 明确排除的能力

行为：本期不交付录屏（含麦克风）、滚动长图、截图历史画廊、云分享、云端 OCR。

适用与失败边界：托盘或菜单栏常驻、设置入口、开机启动选项不属于历史画廊。本机离线 OCR（R4）不属于云 OCR。系统文件对话框保存不属于云分享。未完成态的默认窗口主界面由 R7 排除，不在此重复。

验收：

- 界面与设置中没有录屏、历史画廊或云上传入口
- 交付说明与行为均不要求滚动拼接长图或把图像送到网络识别
